## 1-2. 출제 영역 (2026 1학기 기말 기준)

- **교과서 지문 (L3 파락호 / L4 정크오케스트라)** — 어법 밑줄, 내용 일치/불일치, 핵심어휘 빈칸
- **공통 어법** — if 용법 구별, 가목적어 it, 분사 후치수식, 어법상 옳은 문장 고르기, 밑줄 오류 판별
- **공통 어휘** — 영영풀이 매칭, 핵심어휘 빈칸
- **공통 대화문** — [A][B] 대화 일치/불일치, 속담·관용표현

## 1-3. 어법 출제 포인트

기출 확인된 항목:
- **if 명사절 vs 부사절 판별**
- **가목적어 it** 구문
- **분사 후치수식** (playing 등)
- **어법상 옳은 문장** 고르기 (밑줄 5개 중 적절한 것)
- **밑줄 오류 판별** (짝 형태)

## 1-4. 대비 방식

- 교과서 본문을 **문장 단위로** 어법·어휘 포인트 추출

- 속담·관용표현은 교과서 등장분 중심 (예: No pain no gain)
