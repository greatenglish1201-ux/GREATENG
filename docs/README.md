## 각 학교 파일 구조

- **1부 출제 원리** — 유형별 지침. 새 발견이 있으면 해당 항목을 **수정**(덮어쓰기)
- **2부 시험 기록** — 시험마다 아래로 **추가**(append)
- **3부 미해결 과제** — 다음에 채워야 할 것

## 사용법

### 출제할 때
1. [출제절차.md](출제절차.md)의 **B. 프롬프트 템플릿**을 복사해 빈칸을 채웁니다
2. **해당 학교 md + 기출복원 docx** 두 파일을 대화에 첨부합니다
   (자동으로 읽히지 않으므로 직접 첨부해야 적용됩니다)
3. 체크리스트 순서대로 진행합니다 — 특히 **유형별 분할 확인**

### 시험 후
1. 기출 복원 → 적중 분석
2. 해당 학교 md **2부**에 기록 블록 추가
3. 새 원리 발견 시 **1부** 해당 항목 수정
4. `results.js`에 시험 객체 추가
