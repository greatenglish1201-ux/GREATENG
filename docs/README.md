## 각 학교 파일 구조

- **1부 출제 원리** — 유형별 지침. 새 발견이 있으면 해당 항목을 **수정**(덮어쓰기)
- **2부 시험 기록** — 시험마다 아래로 **추가**(append)
- **3부 미해결 과제** — 다음에 채워야 할 것

## 사용법

### 출제할 때 (v2, 2026-11-15~)
1. [출제절차.md](출제절차.md) **F. 대화 시작 프롬프트**를 채워 보냅니다 — 첨부 필요 없음
   (Claude가 저장소 `docs/`, 드라이브 기출DB, 통합분석어시스트를 직접 읽음)
2. 중등은 데이터 점검(`exam_data_check.py`) → 커버리지표 확인 ① → 완성본 확인 ②
3. 고등은 기존처럼 유형별 분할 확인

### 시험 후 (출제절차 E)
1. 기출 복원(→ 드라이브 기출DB) → 적중 분석
2. 해당 학교 md **2부**에 기록 블록 추가
3. 새 원리 발견 시 **1부** 해당 항목 수정
4. `results.js`에 시험 객체 추가
