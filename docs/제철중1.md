## 1-4. 학교 변형 방식
- 본문을 **A/B 대화로 바꾸고** [ ] 어법 선택을 넣음(dondurma: sticky → tastes [stickier])
- 본문에 인물 소개 문장 추가 후 지칭 연결(gelato: "I'm Annie")
- 실용문 원문 유지 + 한 문장 추가해 **날짜 함정**(Ming's Kitchen "three days from today")
- 교과서 조언 2개 + 다른 인물 조언을 살짝 바꿔 오답으로 + 창작 조언 5개
- 학교는 문항 간 교차 힌트를 막지 않음(2025·2026 모두)
