- **⚠️ 반드시 exportMimeType을 지정해야 전체 시트가 옵니다**

```

  fileId="1_dt7nLh4c9eIRL-05zrGOHFc_m39baVZ7tCelAhRYzw",
  exportMimeType="application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"
```

- 지정 안 하면 **첫 시트 CSV만** 옴 (content가 `a2V5LHNjaG9vbC...` = "key,school..." 형태)

```python
import json, base64
d = json.load(open("<tool_results 경로>"))
inner = json.loads(d[0]['text'])

open('assist.xlsx','wb').write(raw)
```

## 5단계 — 유형별 제작 ⭐ 반드시 분할 진행

☐ 제목 → ☐ 빈칸 → ☐ 삽입 → ☐ 순서 → ☐ 함축 → ☐ 어휘 → ☐ 어법 → ☐ 요약 → ☐ 흐름무관

**각 유형마다**:
1. 기출의 해당 유형 문항을 **먼저 다시 읽는다**
2. 그 스타일로 제작
3. **원장 확인받고 다음 유형으로** ⚠️ 한 번에 다 만들면 방향이 틀린 채 끝까지 감

**기출에서 특정 유형만 뽑아 읽는 법** (ref.txt 기준)
```python
import re
txt = open('ref.txt', encoding='utf-8').read()
blocks = re.split(r'\n(?=\d{1,2}\.\s)', txt)          # 문항 단위 분할
for b in blocks:
    head = b.split('\n')[0]
    if '제목으로 가장 적절한' not in head: continue      # ← 유형 키워드
    print(b[:1500])
```
유형별 키워드: `제목으로 가장 적절한` / `빈칸에 들어갈` / `주어진 문장이 들어가기` / `이어질 글의 순서` / `의미하는 바로` / `낱말의 쓰임` / `네모` / `어법상 틀린` / `한 문장으로 요약` / `전체 흐름과 관계 없는` / `내용과 일치하지 않는`

**확인할 때 볼 것**:
- 난이도가 기출과 유사한가 (쉬우면 오답이 지문 밖 내용일 가능성)
- 정답이 지문 표현 그대로인가 (그러면 단어 찾기로 풀림)
- 선지 5개 형태가 균질한가 (정답만 다르면 형태로 찍힘)

# C. 자주 막히는 지점 요약

| 증상 | 원인 | 예방 |
|---|---|---|
| 문제가 기출과 형식이 다름 | 시트 출제DB를 그대로 씀 | 프롬프트에 "창작할 것" 명시 |
| 배정 후 재작업 | 그 지문에 해당 유형 제작 불가 | 2단계에서 제작 가능 여부 먼저 확인 |
| 난이도 전면 재조정 | 난이도 방침을 늦게 전달 | 1단계에서 확정 |
| 선지가 너무 쉬움 | 오답이 지문에 없는 내용 | 오답을 지문 표현에서 인용 |
| 정답이 티남 | 정답만 형태가 다름 | 선지 5개 형태 균질화 |
| 정답이 단어 찾기로 풀림 | 정답이 지문 표현 그대로 | 정답은 재진술 |
| 범위 밖 문항 다수 미적중 | 모의고사·외부지문 구간 누락 | 1단계에서 포함 여부 확인 |
| 시트에서 첫 탭만 옴 | exportMimeType 미지정 | 0-1단계 코드 그대로 사용 |
| 새 창에서 진행상황 유실 | 확정본을 텍스트로 안 넘김 | B-2절 — 유형마다 확정본 정리 요청 |
