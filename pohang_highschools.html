이 내용은 경상북도포항교육지원청이 공고한 「2026학년도 평준화지역(포항시) 일반고등학교 입학전형 요강」 공문을 기반으로 작성한 참고 요약입니다.
2027학년도 전형 일정은 2026년 하반기(8~9월) 공고 예정이며 아직 미확정입니다. 입시 결정 전 반드시 경북 고입전형포털(hischoolgbe.kr) 공식 원문을 확인하세요. 본 페이지의 오류·변경으로 인한 불이익에 대해 책임지지 않습니다.

🏫 포항 평준화 대상 (14개교)

  • 포항 학군 내 일반고 14개교 해당
  • 경상북도 소재 중학교 졸업(예정)자 또는 경북 거주자
  • 대구 군위군 소재 중학교 졸업예정자도 지원 가능
  • 자사고·외고 동시 지원 가능 (불합격 시 평준화 2순위부터 배정)

🗺️ 비평준화 학교 (남구)

  • 영일고, 포항동성고, 오천고
  • 각 학교 자체 원서 접수·전형
  • 농어촌 특별전형 해당 3개교
  • 수도권 대학 농어촌 가산점 혜택 적용 가능

🏫 배정 방식

  • 무시험 전산 배정 (추첨)
  • 학교군: 전산 추첨 배정
  • 중학구(학교군 외 지역): 추첨 없이 해당 중학교 자동 배정
  • 거주지 기준 학교군·중학구 소속 확인

📋 지원 자격

  • 해당 학교군·중학구 거주자
  • 초등학교 졸업(예정)자
  • 초등학교 졸업학력 검정고시 합격자
  • 외국 또는 이북지역에서 6년 이상 수료자

📝 원서 접수

  • 초등학교 졸업(예정)자: 출신 초등학교에서 제출
  • 검정고시 합격자: 포항교육지원청에 직접 제출
  • 수수료: 없음
  • 남·여별 배정원서 색 구분 (남: 흰색, 여: 노란색)

🗺️ 학구도 확인

  • 거주지별 배정 학교군·중학구 확인 필수
  • 교육부 학구도 서비스 ↗
  • 포항교육지원청 홈페이지 확인 권장
  • 위장전입 적발 시 최초 배정교로 이관
📌 포항 학교군: 포항시 제1·2학교군, 연일학교군, 오천학교군으로 구분. 학교군 외 지역은 중학구로 해당 학교에 자동 배정. 학구도 서비스(schoolzone.emac.kr)에서 우리 집 주소로 배정 학교 확인 가능.

  • 나이스(NEIS) 전산 입력 후 원서 제출

🎯 전산 배정

  • 장소: 포항교육지원청

📢 결과 발표

  • 발표: 1월 중순
  • 포항교육지원청 홈페이지 게재
  • 배정통지서: 출신 초등학교에서 배부
  • 검정고시 합격자: 교육지원청 직접 수령
